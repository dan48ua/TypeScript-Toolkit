# TypeScript Toolkit

A collection of utility classes and architectural patterns implemented in TypeScript. This repository demonstrates the use of core software engineering concepts for clean architecture and modular design.

## Features
* **Event Bus (`eventBus.ts`)**: Implementation of the publish-subscribe pattern for decoupled communication.
* **Repository Pattern (`userRepo.ts`)**: Abstraction layer for scalable data access.
* **Data Transfer Objects (`dto.ts`)**: Structured data passing between subsystems.
* **Validation & Logging (`validation.ts`, `logger.ts`)**: Reusable utilities for input sanitization and system monitoring.

## Tech Stack
* TypeScript
* Node.js
